# ABOUT THIS PROJECT
- This is a project that served as the final project for my high school graduation (the practical part of the graduation)
- In a quick summary of this project, it's essentially a copy of Google Forms
- The project is functionally mostly PHP, most of the JavaScript is used for a better UI/UX.
- Results and graphs, as well as actions with them, are handled with JavaScript (Chart.js library)
